# Soft-HeartDevSpace 0.1.0

**English** · 中文见下方

A Windows control panel for connecting local projects to ChatGPT through your own HTTPS domain.

This first release includes an English / Chinese interface, project-folder and domain settings, Cloudflare login and tunnel creation, ChatGPT OAuth instructions, and a hidden connection heartbeat. The background task checks the service, tunnel, and public address on a nominal 30-second schedule and recovers failed components with startup grace and retry cooldowns.

Download the Windows x64 ZIP, extract the entire folder, and open `Soft-HeartDevSpace.exe`. Keep the `_internal` folder beside the executable. Prerequisites are Node.js 24 LTS, Git for Windows, cloudflared, a Cloudflare-managed domain, and an eligible ChatGPT account. The app can install DevSpace 1.0.8. The executable is unsigned.

Validation for this release: 12 configuration / API tests, 12 recovery-policy checks, a packaged-app smoke test, and a Windows integration test using the real DevSpace engine with a local tunnel fixture. The integration test completed OAuth and a file read, recovered a terminated service, and reused its prior authorization after recovery. Actual Cloudflare account setup and ChatGPT authorization are completed by each customer.

本版本通过 12 项配置与接口测试、12 项恢复策略检查、打包程序启动检查和 Windows 集成测试。集成测试使用真实 DevSpace 与本地隧道测试程序，完成授权及文件读取，并验证进程退出后恢复、原授权继续有效。真实 Cloudflare 账户配置与 ChatGPT 授权由使用者在自己的账户中完成。
