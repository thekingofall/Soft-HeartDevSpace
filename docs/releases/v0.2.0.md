# Soft-HeartDevSpace 0.2.0

English · [简体中文](#简体中文)

FRP can now complement Cloudflare Tunnel. Choose Cloudflare, FRP, or dual transport in the Windows control panel. A Linux HTTPS gateway can keep one ChatGPT MCP address while selecting a healthy route.

This release includes private STCP templates, an nginx gateway example, a systemd health checker with failover and recovery hold times, and a Windows process supervisor. Background workers use a windowless launcher with child-process cleanup. A pending-gateway setting supports deployments awaiting public activation.

Setup requires your own relay, a valid certificate, and any domain registration required by the hosting region. FRP and nginx are separate dependencies. Read the [FRP guide](../FRP.md) before changing DNS. Existing Cloudflare installations keep the default connection mode and their OAuth state.

Validation covers configuration and route decisions, failed-reload recovery, actual Windows service recovery with OAuth reuse, console suppression and child cleanup, and the packaged application. Public route availability depends on the deployed server, network, certificate, and domain setup.

Download the Windows x64 ZIP and extract the complete folder. SHA256SUMS.txt accompanies the archive. The Windows binaries are unsigned.

## 简体中文

0.2.0 新增 FRP 补充通道，可在 Windows 控制台选择 Cloudflare、FRP 或双通道。Linux HTTPS 网关可保持同一个 ChatGPT MCP 地址，并根据健康检查切换线路。

软件附带 STCP 私有通道模板、nginx 网关示例、自动切换与恢复回切检查器。Windows 后台启动器关闭控制台分配，并清理服务所属子进程。网关等待启用期间可使用专门的等待模式。

部署需要自己的中转服务器、有效证书及所在地区要求的域名备案。FRP 与 nginx 需单独安装。切换 DNS 前请阅读[中文设置指南](../FRP.zh-CN.md)。已有 Cloudflare 安装沿用默认连接模式及 OAuth 状态。

验证涵盖配置与线路判断、网关重载失败恢复、Windows 服务自动恢复与 OAuth 复用、静默启动及子进程清理、软件打包运行。公网线路可用性取决于实际服务器、网络、证书和域名配置。

下载 Windows x64 ZIP 后完整解压。发布附件提供 SHA256SUMS.txt 校验值；Windows 程序尚未进行代码签名。
